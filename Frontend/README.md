# BlogSpace - Full Stack Blog Application

## About
BlogSpace is a blog application with user
registration, login, and blog creation.

## Technologies
- HTML, CSS, JavaScript
- Node.js
- Express.js
- MongoDB
- JWT Authentication

## Features
- User registration
- User login
- Create blog
- View all blogs
- View personal blogs
- Password hashing

## Setup
1. Clone this repository.
2. Navigate to backend.
3. Run npm install.
4. Configure your .env file.
5. Run npm run dev.
6. Open the frontend using Live Server.

## API Endpoints
POST /api/auth/register
POST /api/auth/login
POST /api/blogs
GET /api/blogs
GET /api/blogs/mine
